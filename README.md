# MintGram для Android

Нативный клиент (Kotlin + Jetpack Compose) к серверу MintGram. Работает с тем же REST API и WebSocket `/ws`,
что и сайт, поэтому все аккаунты, чаты и сообщения общие.

## Как собрать
1. Установите Android Studio (Koala или новее).
2. File → Open → выберите эту папку, дождитесь Gradle Sync.
3. Подключите телефон (отладка по USB) или эмулятор и нажмите Run.
   APK: Build → Build Bundle(s) / APK(s) → Build APK(s).

## Адрес сервера
По умолчанию `https://aged-pond-26957.pktriot.xyz` (app/build.gradle.kts → DEFAULT_SERVER).
Если адрес туннеля поменяется, его можно изменить на экране входа («Адрес сервера») без пересборки.

## Что есть
Вход, регистрация с кодом из почты, личные чаты, общий чат, «Избранное», группы и каналы, ответы,
редактирование, удаление, реакции, фото (отправка и просмотр), статусы «в сети»/«печатает…», галочки прочтения,
профиль и аватарка, поиск людей, уведомления, пока приложение запущено,
голосовые и видеозвонки 1 на 1 (см. ниже).

## Чего пока нет
Push в закрытом приложении (нужен FCM или фоновая служба): входящий звонок приходит, только пока приложение запущено
и связано с сервером.

## Звонки
Звонки работают через WebRTC (`io.getstream:stream-webrtc-android`) и тот же сигналинг, что и на сайте
(`server/calls.js`), поэтому приложение и браузер звонят друг другу в любых сочетаниях.
- Кнопки «Позвонить» и «Видеозвонок» — в шапке личного чата. Журнал звонков сервер пишет в чат сам.
- Входящий звонок: экран с «Принять/Отклонить» и мелодия; при свёрнутом приложении — уведомление
  (на Android 14+ полноэкранный показ над блокировкой может потребовать разрешения в настройках приложения).
- Во время звонка: микрофон, камера, смена камеры, динамик. Идущий звонок держит служба на переднем плане.
- ICE/TURN приложение получает с сервера (`/api/config`); для мобильного интернета настройте TURN
  в `MINTGRAM_ICE_SERVERS` по инструкции сайта.
- Приложение просит разрешения на микрофон и камеру при первом звонке.
